# Nowhere’s End Herbarium flipbook

Public static web version of the Nowhere’s End botanical field guide. Open `index.html` from the hosted Pages URL. It includes original generated botanical plates, Terpedia QR codes, and TTB label thumbnails. Blend membership and traditional-use descriptions are drawn from the public Nowhere’s End herb library.

The web book uses the vendored HTML page-turn engine [StPageFlip (`page-flip@2.0.7`)](https://github.com/Nodlik/StPageFlip), under MIT; license is included in `assets/vendor`. It opens on a closed cover and shows two herb pages side-by-side in landscape mode.
